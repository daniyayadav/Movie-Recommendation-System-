# 🎬 Movie Recommendation System using Machine Learning

A machine learning–based **Movie Recommendation System** built with **Python** that suggests movies to users based on similarity. This project demonstrates the practical application of data preprocessing, feature extraction, and recommendation logic.

---

## 📌 Project Overview

Recommendation systems are widely used by platforms like **Netflix, Amazon, and Spotify** to personalize user experience.  
This project recommends movies by analyzing similarities between movie features using **content-based filtering**.

---

## 🚀 Features

- Content-based movie recommendations  
- Uses cosine similarity for accurate suggestions  
- Data preprocessing and feature extraction  
- Simple and beginner-friendly implementation  
- Jupyter Notebook based project  

---

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **NumPy**
- **Scikit-learn**
- **Jupyter Notebook**

# 🎬 Movie Recommendation System using Machine Learning

## ⚙️ Working Methodology

1. Load the movie dataset  
2. Clean and preprocess the data  
3. Select relevant features for recommendation  
4. Convert text data into vectors  
5. Calculate similarity using cosine similarity  
6. Recommend movies based on user input
